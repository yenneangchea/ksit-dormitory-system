Allocation Enforcement & Security

Waterfall Algorithm

  • Strict Lock Detection: Automatically identifies and skips rooms with is_locked = true.
  • Capacity Compliance: Only considers rooms where occupied_count < capacity.
  • Dynamic Re-routing: Redirects students to the next available compatible room in the sequence.

Drag-and-Drop UI

  • Visual Blocking: Prevents dropping student cards into locked or full room slots.
  • Real-time Validation: Triggers immediate error feedback if an manual override is attempted.
  • State Sync: Ensures the UI reflects the latest database lock status across all portals.
