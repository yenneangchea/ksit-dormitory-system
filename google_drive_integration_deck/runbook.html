Production activation

Vercel activation is a six-step controlled handoff

The code is deployment-ready. Google Drive becomes the primary store only after the school administrator completes the credential, permission, and migration steps below.

1

Enable Google Drive API

In the Google Cloud project, enable the Google Drive API used by the storage service account.

2

Create service account

Generate a dedicated service-account JSON key. Treat it as a backend-only production secret.

3

Share the root folder

Grant the service account Editor access to the KSIT application root folder in the school Drive.

4

Set two Vercel secrets

GOOGLE_SERVICE_ACCOUNT_JSON
GOOGLE_DRIVE_ROOT_FOLDER_ID

5

Apply the additive migration

Run run-google-drive-storage-migration.mjs from a secure machine with database access.

6

Redeploy & verify

Create a labeled Student application, then confirm Manager access and Drive folder placement.

Success condition: one submission produces five artifacts in one deterministic student folder.Do not set only one Drive variable.
