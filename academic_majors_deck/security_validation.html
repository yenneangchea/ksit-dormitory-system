Security Architecture & Production Deployment

  • Role-Based Access Control (RBAC)

    Strict enforcement of Admin-only privileges for academic catalog modifications, bulk imports, and audit log access.

  • Row Level Security (RLS)

    Database-level protection on audit tables ensures that sensitive snapshots and administrator identities are only accessible via authorized service roles.

  • Same-Project API Dispatching

    Unified Vercel deployment routes all API traffic through the primary domain, maintaining secure session persistence and CORS integrity.
