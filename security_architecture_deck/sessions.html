Secure Token & Session Management

Protecting user identities and preventing unauthorized session extraction

HttpOnly & Secure Cookie Persistence

JWT session tokens are stored in HttpOnly, Secure, and SameSite=Lax cookies, preventing client-side XSS extraction and mitigating CSRF risks.

BCrypt Password Hashing

All user credentials are salted and hashed using BCrypt with a robust work factor. Plaintext passwords are never stored, logged, or transmitted.

HMAC-SHA-256 Telegram Verification

Mini App initData is cryptographically verified server-side using HMAC-SHA-256 with the bot token, ensuring Telegram identities cannot be spoofed.
