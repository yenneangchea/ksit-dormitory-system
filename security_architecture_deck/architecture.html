Multi-Tier Defense-in-Depth Architecture

Isolating the database from direct client queries while enforcing programmatic RBAC

1. Next.js 15 Frontend

Runs on Vercel Edge & Serverless. Renders role dashboards for Admin, Manager, Teacher, and Student with HttpOnly cookie sessions.

2. Express API Backend

Consolidated API gateway executing authentication checks, bcrypt validation, RBAC enforcement, and service-role database calls.

3. Supabase PostgreSQL

Secured with mandatory RLS on all 16 tables. Direct public data APIs are revoked; only the service role performs queries.
