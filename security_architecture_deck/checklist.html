Security Operating Checklist

Actionable best practices for ongoing system maintenance and protection

Vercel: Secret Isolation

Ensure SUPABASE_SERVICE_ROLE_KEY is never prefixed with NEXT_PUBLIC_ and exists only in server-side environment variables.

Supabase: Mandatory RLS

Enable Row-Level Security immediately upon creating any new table. Revoke direct public grants to enforce backend mediation.

GitHub: Access Control

Use protected branches for 'main' and ensure GitHub Secret Scanning is active to prevent accidental credential leaks in commits.

Manus AI: Security Audits

Leverage Manus AI for periodic security reviews of new features and to automate database compliance checks via SQL triggers.

Auth: Session Hardening

Regularly audit user roles and ensure password reset flows remain protected by multi-factor verification (Telegram OTP).

Data: Backup Resilience

Maintain automated daily database dumps and verify recovery procedures monthly to ensure business continuity.
